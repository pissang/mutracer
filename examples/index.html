MuTracer examples

  • Basic: procedural geometry, OpenPBR materials, an area light and an HDR environment.
  • Three.js: a Three.js scene with a glTF model, converted with fromTHREEScene.
  • Animation: a procedural skinned cylinder with bone animation and a morph target.
  • Instancing: 100 shared cubes with a matrix edit notification.
  • Caustics: a glass sphere under a spotlight; light tracing requires WebGPU.
  • Advanced: OpenPBR layers, shadow catcher, OIDN denoising and offline PNG export.

MuTracer uses WebGPU when available and falls back to WebGL 2.

For an interactive viewer (drop a glTF or HDR, edit materials, export PNGs), open the viewer (npm run viewer locally).
