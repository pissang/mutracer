Procedural materials from node graphs

MaterialGraph drives every OpenPBR input from a network of MaterialX nodes: noise, patterns, ramps, math and images. WebGPU compiles procedural graphs into the path tracer; both backends render image graphs. Read .mtlx files with parseMaterialX. 

    import { parseMaterialX } from '@meimu/mutracer/materialx';

const { values, graph } = parseMaterialX(mtlxText);
mesh.material = new OpenPBRMaterial({ ...values, graph });
engine.update();

      Engine

      Offline-quality light transport

      • Light transport

        Unidirectional path tracing with next-event estimation and MIS over rect, disk, cylinder, sphere, IES spot, directional and HDR environment lights. Continuous-wavelength dispersion.

      • OpenPBR 1.1 surface

        F82 metals, anisotropic specular and coat, fuzz, thin film, dispersive transmission with volume scattering, subsurface scattering and ray-marched displacement.

      • Caustics WebGPU · experimental

        Light tracing for directly visible receivers and photon mapping for caustics seen through glass or water.

      • Millions of triangles

        Two-level BVH with binned-SAH BLASes built in parallel Workers, in JavaScript or TinyBVH WebAssembly. Moving instances only refits the TLAS; new meshes upload only their geometry.

      • Low noise, then denoised

        Owen-scrambled Sobol or blue-noise ZSobol samples, variance-driven adaptive sampling, and albedo- and normal-guided Intel OIDN or JNLM denoising.

      • Fits your app

        Incremental THREESync for Three.js scenes, your own GPUDevice, OffscreenCanvas workers, AOVs, post-process passes, HDR output and PNG export.

      Get started

      Path trace a Three.js scene

      Keep building with Three.js. THREESync converts the scene once and follows transform, material and light edits on every frame.

      Getting started → Three.js integration → Examples → 
      import { Engine, RenderLoop } from '@meimu/mutracer';
import { THREESync } from '@meimu/mutracer/three';

const engine = new Engine({ canvas });
const sync = new THREESync(engine, { scene, camera, controls });
const loop = new RenderLoop(engine, { sync });
loop.start();

// Denoise the converged frame with Intel OIDN (WebGPU)
loop.final.setDenoiser({ type: 'oidn' });
